## What's new in this release

### ✨ New
- **App icon** — NX-Librarian now shows its own icon in the taskbar, alt-tab, and window title bar instead of the default system feather
- **In-app release notes** — the update dialog now shows the actual changelog when a new version is available (previously showed "(No release notes)" due to a CI workflow bug)

### 🔧 Fixed (from beta.30)
- Neon mode-selection screen with emoji icons (🎮 🔄 🎁) in each panel's neon color
- Multi-layer neon glow on icons, titles, and subtitles with near-white hot core
- Spotlight sibling-clearing — hovering one panel immediately resets any stuck spotlight on the others
- Subtitle spacing improved

### 📦 Installation
Download `NX-Librarian-*-Windows-Setup.exe` and run it. No admin rights required — installs to `%LocalAppData%\NX-Librarian`.

> Existing installs upgrade automatically via **Menu → Check for Updates**.
